Notas de Lançamento

Acompanhe todas as novidades, correções de bugs e melhorias implementadas em cada versão do K-Code IDE.

K-Code 1.1.0 Versão Estável

  • Salvamento automático do estado do compilador, restaurando a última configuração utilizada ao reabrir a IDE.

  • Animações de responsividade aprimoradas, proporcionando transições mais fluidas e menos travamentos.

  • Sistema de busca global em todos os arquivos do projeto (Ctrl + Shift + F), com resultados em uma nova aba do painel inferior e navegação direta até a linha correspondente.

  • Sistema de salvamento automático configurável (desativado, ao perder o foco ou a cada intervalo de tempo), além da opção Salvar tudo (Ctrl + Shift + S).

  • Histórico de arquivos e pastas recentes, permitindo reabrir rapidamente projetos utilizados anteriormente.

  • Paleta de comandos integrada (Ctrl + Shift + P), centralizando as principais funcionalidades e ações da IDE em uma única ferramenta de busca.

  • Minimapa integrado à lateral do editor para facilitar a visualização e navegação pelo código.

  • Terminal interativo integrado ao painel inferior, com suporte a CMD, PowerShell e Bash para execução de comandos diretamente na IDE.

  • Fechamento automático de parênteses, chaves e aspas, com destaque dos delimitadores correspondentes.

  • Correção de Bugs e melhorias gerais de estabilidade.

K-Code 1.0.0 Versão Estável

  • Lançamento oficial da IDE focada em C e suporte a multiplataformas.

  • Suporte robusto a múltiplas linguagens, sendo elas:
    • C
    • Java
    • Python
    • HTML
    • CSS
    • JavaScript
    • JSON

  • Ferramentas integradas de compilação, execução e diagnóstico de erros (Problems), além de validação e formatação automática para arquivos JSON.

  • Servidor local integrado com atualização automática (live reload) no navegador para páginas HTML, CSS e JS.

  • Gerenciador de arquivos completo com explorador lateral, suporte a arrastar e soltar (drag and drop), e ferramenta para empacotar scripts Python em executáveis
    .exe via PyInstaller.

  • Interface moderna e customizável com suporte a múltiplos temas visuais e margem interativa com recolhimento de blocos (code folding).

  • Correção de Bugs

K-Code Beta Em Testes

  • Correção de bugs na indentação automática.
  • Adição de atalhos rápidos para compilação.

K-Code Alpha Experimental

  • Versão inicial de testes estruturais da IDE.
  • Estruturação básica do editor de código em C.
